Research

How do we make large-scale personalization both efficient and reliable?

I work on LLM post-training and generative recommendation. Lately I've been focused on inference cost: getting LLMs fast and cheap enough to run for millions of users. At Comcast, I build teacher-student pipelines that generate user profiles, use LLMs to improve recommendations for new and long-tail items, and serve these models to 5 to 10 million users.

Generative & sequential recommendation

LLM-generated synthetic interactions and LLM-guided negative selection for cold-start and long-tail items (CIKM 2026, EACL 2027, NAACL 2027).

LLM post-training at scale

SFT, DPO, and distillation to train small models from larger teachers, cheap enough to deploy (NAACL 2027).

Efficient inference

Self-hosted vLLM serving that runs LLM personalization at roughly 650× lower cost than managed APIs.

Experience

ML Research Engineer, Comcast

May 2024 – Present
Recommendation and Arbitration team · Washington, D.C.
  • LLM post-training for user profile generation: built a teacher-student post-training pipeline for a 3B-parameter student model, using SFT with auxiliary reasoning objectives, DPO for alignment, and off- and on-policy evaluation. The fine-tuned models then act as teachers for downstream recommendation tasks.
  • LLM data augmentation for cold-start recommendation: designed an LLM-based pipeline injecting synthetic user histories for cold-start items, achieving an 80% relative NDCG improvement while maintaining overall quality (CIKM 2026, EACL 2027).
  • Efficient inference at scale: built a self-hosted vLLM serving setup on 4×A100 GPUs that reaches about 326k tokens/sec for user profile inference across 5 to 10 million users, roughly 650× cheaper than managed APIs at that scale.
  • Xfinity Campaign Manager forecasting: built campaign-level time-series forecasting models and ETL pipelines (Spark, Databricks, SQL) across EU and NA markets, with automated dashboarding for weekly media-buy pacing and budget allocation.
  • Content discoverability simulator: architected a large-scale simulation using LLM-generated synthetic queries and historical clustering to evaluate upcoming content in the Xfinity TV ecosystem (RecSys 2025).
  • Search quality evaluation: deployed a hybrid system combining heuristics and LLMs for real-time moderation of 5M+ daily voice queries; introduced a time-aware dynamic lexicon reducing false positives by 35% (SIGIR 2025).
